This directory adapts the Admin, Layout, AppSidebar, and theme components from
https://github.com/marmelab/shadcn-admin-kit (MIT; license included).

The shell uses ra-core resource routing and persistent theme preferences. The
sidebar uses the application's existing Radix shadcn primitives rather than
migrating them to Base UI. Optional telemetry is disabled. Domain actions stay
on the existing Company Brain API. Neutral theme tokens come from the upstream
kit. Existing dependency versions are preserved.
