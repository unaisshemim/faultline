# AI Elements

`attachments.tsx` is the Vercel AI Elements attachment component from
https://github.com/vercel/ai-elements/blob/main/packages/elements/src/attachments.tsx
with imports adapted to this application's shadcn primitives. Used for draft
attachments and saved user-message attachments. Docs: https://elements.ai-sdk.dev/components/attachments

`confirmation.tsx` is the official AI Elements confirmation component, with local shadcn imports. Task proposals use native AI SDK approval-requested states. Decisions are applied to authoritative stored proposals by the backend.
